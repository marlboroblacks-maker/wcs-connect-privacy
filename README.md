# WCS Connect privacy and support

Public pages for the WCS Connect macOS and iOS app by WCS Engineering LLC.

- `index.html`: privacy policy
- `support.html`: support and safe setup information

Publish these files at the root of the proposed public GitHub repository `marlboroblacks-maker/wcs-connect-privacy` and enable GitHub Pages from the main branch root. Verify the policy at `https://marlboroblacks-maker.github.io/wcs-connect-privacy/` and support at `https://marlboroblacks-maker.github.io/wcs-connect-privacy/support.html` before adding the URLs to App Store Connect or distributing build 35. Keep credentials and device secrets out of this repository.
